# The MCP server stays local: Codex yes, ChatGPT chat no

The MCP server runs only over stdio on the Mac. Codex supports local stdio servers, also inside the ChatGPT desktop app, so it works; ChatGPT chat accepts only remote servers over HTTPS, and full read/write tools there are for Business and Enterprise plans. Reaching ChatGPT chat would need a tunnel (OpenAI's Secure MCP Tunnel or a public one) for a tool that in any case only works on files on the Mac, so ChatGPT chat is not supported.
